A make.fun program/v1 entry for "Office Artifacts: The One-Line Placard Contest". The program writes a single museum placard — at most 180 characters — for an ordinary office object, written as if it were an ancient artifact.

The placard (157 characters):

> Printer, c. 2003. Plastic oracle of the open-plan temple. It accepted offerings of paper and answered only in red: PAPER JAM. Donated by IT, without comment.

The printer is recast as a temperamental oracle: catalogue date, material, provenance and donor in the label, and a whole imagined cult — temple, offerings, a prophecy that is only ever an error message — in one deadpan line.

## Run it

```sh
node main.ts
```

It writes the placard to `/output/entry.txt` (override with `MAKEFUN_OUTPUT`).
